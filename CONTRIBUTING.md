# Contributing

- **Bug fixes** are welcome as pull requests.
- **Ports to new platforms** are welcome too. Please open an [issue](https://github.com/K-Adam/UT2004/issues) first, so that work does not conflict. When you open the pull request please link a video showcasing the game running on that new platform.
- **New features** always need an issue first.

## Generative AI

You are allowed to use generative AI tools to assist in writing your contribution, but you must mention this in your pull request description.  

AI tools may not be listed as co‑authors, used to co‑sign commits, or given credit through "Assisted‑by" or similar commit trailers.  

Every pull request must be submitted by a human contributor who takes accountability for the changes. Descriptions of pull requests and replies to review comments must be written in the contributor's own words, please do not use generative AI for communication.
